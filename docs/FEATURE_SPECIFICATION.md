# NIDHI - Feature Specification

This document defines all features included in the MVP.

---

# 1. Authentication

Purpose

Provide secure authentication before accessing investor data.

Features

- Sign Up
- Login
- Forgot Password
- Logout
- Firebase Authentication
- Protected Routes

---

# 2. Onboarding

Purpose

Collect information required for personalized investment recommendations.

Information Collected

- Full Name
- Age
- Occupation
- Annual Income
- Investment Experience
- Investment Goal
- Investment Horizon
- Monthly Investment Capacity
- Risk Appetite

Goals

Examples

- Wealth Creation
- Retirement
- Buying a House
- Child Education
- Emergency Fund
- Passive Income

Risk Levels

- Conservative
- Moderate
- Aggressive

---

# 3. Portfolio Import

Purpose

Create a unified investment portfolio.

Supported Sources

- Manual Import (MVP)
- CSV Upload
- Mock Broker Connections
- Mock Bank Accounts

Future Sources

- Account Aggregator
- UIP
- Broker APIs

Portfolio Data

- Stocks
- Mutual Funds
- ETFs
- REITs
- InvITs
- Bonds
- Government Securities

---

# 4. Dashboard

Purpose

Provide a complete overview of the investor's financial position.

Widgets

- Total Net Worth
- Total Investment
- Current Portfolio Value
- Overall Returns
- Portfolio Health Score
- Diversification Score
- Risk Score
- Asset Allocation
- Sector Allocation
- Top Holdings
- Recent Transactions
- AI Insights

Charts

- Portfolio Growth
- Asset Allocation Pie Chart
- Sector Distribution
- Monthly Performance

---

# 5. Portfolio Page

Purpose

View all holdings in one place.

Features

- Search Holdings
- Filter by Asset Type
- Filter by Sector
- Sort by Value
- Sort by Returns
- Investment Details
- Source Information

Holding Details

- Asset Name
- Asset Type
- Quantity
- Average Price
- Current Price
- Current Value
- Profit/Loss
- Allocation Percentage

---

# 6. Portfolio Intelligence

Purpose

Analyze the portfolio using predefined financial rules.

Calculations

- Portfolio Health Score
- Diversification Score
- Sector Concentration
- Asset Allocation
- Liquidity Score
- Risk Score

Insights

Examples

- High exposure to IT sector
- Low fixed-income allocation
- Poor diversification
- Large-cap concentration
- High portfolio volatility

Every insight includes a plain-language explanation.

---

# 7. AI Suitability Engine

Purpose

Recommend suitable investment opportunities.

Inputs

- Portfolio Analysis
- User Goals
- Risk Appetite
- Investment Horizon
- Existing Allocation

Outputs

- Recommended Asset Classes
- Suggested Allocation
- Reason for Recommendation
- Expected Benefits
- Risks
- Suitability Explanation

Possible Recommendations

- Stocks
- Mutual Funds
- ETFs
- REITs
- InvITs
- Corporate Bonds
- Government Securities

---

# 8. Smart Investment Hub

Purpose

Allow users to explore and invest in recommended assets.

Tabs

## Recommended

Personalized AI recommendations.

## Explore

Browse all supported investment categories.

## Trending

Popular investment opportunities.

Features

- Asset Overview
- Expected Returns
- Risk Level
- Liquidity
- Investment Objective
- AI Summary

Investment Flow

Asset

↓

View Details

↓

Invest Now

↓

Redirect to Partner Platform

↓

Portfolio Refresh

---

# 9. AI Financial Assistant

Purpose

Allow users to ask portfolio-related questions.

Example Questions

- Why is my portfolio risky?
- Why did you recommend bonds?
- Should I invest in REITs?
- Explain diversification.
- What happens if the market falls?
- How can I reduce portfolio risk?

The AI should answer using the user's portfolio context.

# 12. Settings

# MVP Scope

Included

✅ Authentication

✅ Onboarding

✅ Portfolio Import (Mock)

✅ Dashboard

✅ Portfolio Page

✅ Portfolio Intelligence

✅ AI Suitability Engine

✅ Smart Investment Hub

✅ AI Financial Assistant

✅ Learning Center

Excluded

❌ Real Broker Integration

❌ Real Money Transactions

❌ Live Market Data

❌ Portfolio Rebalancing Automation

❌ Robo-Advisory Execution

The MVP focuses on demonstrating the complete user journey using realistic mock data.

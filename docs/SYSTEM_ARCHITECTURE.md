# NIDHI System Architecture

## Overview

NIDHI follows a modern full-stack architecture designed for scalability, modularity, and maintainability.

The application consists of six major layers.

```
                React Frontend
                       │
                       ▼
              FastAPI Backend API
                       │
        ┌──────────────┴──────────────┐
        ▼                             ▼
 Gemini AI Service            PostgreSQL Database
        │
        ▼
 Portfolio Intelligence Engine
        │
        ▼
 Recommendation Engine
```

---

# Architecture Layers

## 1. Frontend Layer

Technology

- React
- Vite
- TypeScript
- Tailwind CSS
- shadcn/ui
- Recharts

Responsibilities

- Authentication
- Dashboard
- Portfolio Visualization
- AI Chat Interface
- Learning Center
- Smart Investment Hub
- User Profile
- Responsive UI

The frontend never performs business logic.

It only displays data returned by the backend.

---

## 2. Backend Layer

Technology

- FastAPI

Responsibilities

- Authentication Verification
- API Endpoints
- Portfolio Processing
- Portfolio Analytics
- Recommendation Logic
- AI Request Handling
- Database Communication

The backend is the central controller of the application.

---

## 3. Database Layer

Technology

- PostgreSQL (Neon)

Responsibilities

Store

- Users
- Investor Profiles
- Holdings
- Transactions
- Portfolio Scores
- Recommendations
- AI Reports
- Learning Content

The database is the single source of truth.

---

## 4. AI Layer

Technology

- Gemini API

Responsibilities

Generate

- Portfolio Explanations
- Recommendation Explanations
- Educational Responses
- AI Chat Responses

Important

Gemini DOES NOT decide investments.

Gemini only explains decisions generated by the application's business logic.

---

## 5. Portfolio Intelligence Engine

Purpose

Analyze the user's portfolio.

Responsibilities

Calculate

- Total Portfolio Value
- Asset Allocation
- Sector Allocation
- Portfolio Health Score
- Diversification Score
- Liquidity Score
- Risk Score

Generate

- Portfolio Insights
- Portfolio Warnings
- Portfolio Opportunities

---

## 6. Recommendation Engine

Purpose

Recommend suitable investment opportunities.

Inputs

- Portfolio Analysis
- Risk Profile
- Investment Goals
- Investment Horizon
- Current Allocation

Outputs

- Recommended Asset Classes
- Suggested Allocation
- Portfolio Improvement Suggestions

Example

Current Portfolio

80% Equity

10% Mutual Funds

10% Cash

↓

Recommendation

Increase Fixed Income Allocation

↓

Suggested Assets

Corporate Bonds

Government Securities

Bond ETFs

↓

Gemini explains why.

# Development Principles

1. Use reusable components.

2. Keep frontend and backend separate.

3. Business logic belongs only in FastAPI.

4. AI is used only for explanations.

5. Use mock data first.

6. Replace mock APIs with real integrations later.

7. Build every module independently.

8. Keep the application modular and scalable.
